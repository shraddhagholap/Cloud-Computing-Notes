# 04 - Cloud Service Models

# ☁️ Cloud Service Models

## 📖 Introduction

Cloud Service Models define **how cloud services are delivered** to users. Instead of purchasing and managing physical hardware and software, organizations can choose different levels of cloud services based on their requirements.

The three primary cloud service models are:

* **IaaS (Infrastructure as a Service)**
* **PaaS (Platform as a Service)**
* **SaaS (Software as a Service)**

Each model offers a different level of responsibility between the **Cloud Provider** and the **Customer**.

---

# What are Cloud Service Models?

Cloud Service Models specify **which IT resources are managed by the cloud provider and which are managed by the customer**.

They help organizations choose the right level of control, flexibility, and management for their applications.

---

# Types of Cloud Service Models

1. Infrastructure as a Service (IaaS)
2. Platform as a Service (PaaS)
3. Software as a Service (SaaS)

---

# Cloud Service Models Overview

| Service Model | Managed by Cloud Provider                     | Managed by Customer                  |
| ------------- | --------------------------------------------- | ------------------------------------ |
| IaaS          | Hardware, Networking, Storage, Virtualization | Operating System, Applications, Data |
| PaaS          | Infrastructure, Operating System, Runtime     | Applications, Data                   |
| SaaS          | Everything                                    | Uses the software                    |

---

# 1. Infrastructure as a Service (IaaS)

## Definition

**Infrastructure as a Service (IaaS)** provides virtualized computing resources such as servers, storage, networking, and virtual machines over the Internet.

The cloud provider manages the physical infrastructure, while the customer manages the operating system, applications, and data.

---

## Features

* Virtual Machines (VMs)
* Storage
* Networking
* Load Balancers
* Firewalls
* Virtual Private Cloud (VPC)

---

## Responsibilities

### Cloud Provider Manages

* Physical servers
* Storage hardware
* Networking
* Virtualization
* Data centers

### Customer Manages

* Operating System
* Middleware
* Runtime
* Applications
* Data

---

## Advantages

* High flexibility
* Full control over the operating system
* Easy scalability
* Pay-as-you-go pricing

---

## Disadvantages

* Customer is responsible for OS updates
* Requires system administration skills
* Security configuration is the customer's responsibility

---

## AWS IaaS Services

* Amazon EC2
* Amazon EBS
* Amazon VPC
* Elastic Load Balancer (ELB)

---

## Real-World Example

A company rents virtual servers from AWS to host its website. The company installs Linux, configures software, and manages the application.

---

# 2. Platform as a Service (PaaS)

## Definition

**Platform as a Service (PaaS)** provides a complete platform for developing, testing, deploying, and managing applications.

The cloud provider manages the infrastructure, operating system, middleware, and runtime environment.

Developers focus only on writing application code.

---

## Features

* Application development platform
* Built-in runtime
* Database integration
* Auto scaling
* Deployment tools

---

## Responsibilities

### Cloud Provider Manages

* Infrastructure
* Networking
* Storage
* Operating System
* Runtime
* Middleware

### Customer Manages

* Application Code
* Application Data

---

## Advantages

* Faster application development
* No server management
* Automatic updates
* Easy deployment

---

## Disadvantages

* Less control over infrastructure
* Vendor lock-in
* Limited customization

---

## AWS PaaS Services

* AWS Elastic Beanstalk
* AWS App Runner
* Amazon RDS
* AWS Lambda (Serverless Platform)

---

## Real-World Example

A developer uploads application code to AWS Elastic Beanstalk, and AWS automatically handles servers, deployment, and scaling.

---

# 3. Software as a Service (SaaS)

## Definition

**Software as a Service (SaaS)** provides complete software applications over the Internet.

Users simply access the application through a web browser or mobile app without installing or maintaining software.

---

## Features

* Ready-to-use software
* Web-based access
* Automatic updates
* Subscription-based pricing

---

## Responsibilities

### Cloud Provider Manages

* Infrastructure
* Networking
* Servers
* Operating System
* Runtime
* Applications
* Data Security

### Customer Manages

* User accounts
* Application settings
* Data entered into the application

---

## Advantages

* No installation required
* Easy to use
* Accessible from anywhere
* Automatic updates

---

## Disadvantages

* Limited customization
* Internet dependency
* Less control over the application

---

## Examples

* Gmail
* Microsoft 365
* Google Workspace
* Dropbox
* Zoom
* Salesforce

---

## Real-World Example

A student uses Google Docs to create documents online without installing any office software.

# Shared Responsibility Model

| Component        | On-Premises | IaaS           | PaaS           | SaaS           |
| ---------------- | ----------- | -------------- | -------------- | -------------- |
| Applications     | Customer    | Customer       | Customer       | Cloud Provider |
| Data             | Customer    | Customer       | Customer       | Customer       |
| Runtime          | Customer    | Customer       | Cloud Provider | Cloud Provider |
| Middleware       | Customer    | Customer       | Cloud Provider | Cloud Provider |
| Operating System | Customer    | Customer       | Cloud Provider | Cloud Provider |
| Virtualization   | Customer    | Cloud Provider | Cloud Provider | Cloud Provider |
| Servers          | Customer    | Cloud Provider | Cloud Provider | Cloud Provider |
| Storage          | Customer    | Cloud Provider | Cloud Provider | Cloud Provider |
| Networking       | Customer    | Cloud Provider | Cloud Provider | Cloud Provider |

---

# Comparison of IaaS, PaaS, and SaaS

| Feature                   | IaaS                  | PaaS           | SaaS           |
| ------------------------- | --------------------- | -------------- | -------------- |
| User Control              | High                  | Medium         | Low            |
| Infrastructure Management | Customer              | Cloud Provider | Cloud Provider |
| Operating System          | Customer              | Cloud Provider | Cloud Provider |
| Application Management    | Customer              | Customer       | Cloud Provider |
| Best For                  | System Administrators | Developers     | End Users      |

---

# Real-World Analogy

Imagine you want to eat a meal.

### On-Premises

You buy groceries, cook the food, clean the kitchen, and maintain everything yourself.

### IaaS

You rent a kitchen with appliances. You cook and manage the meal.

### PaaS

A restaurant provides a ready-to-use kitchen and ingredients. You focus on preparing the dish.

### SaaS

You order food from a restaurant. Everything is prepared and served for you.

# When to Choose Each Model

| Requirement                      | Recommended Model |
| -------------------------------- | ----------------- |
| Full control over servers        | IaaS              |
| Focus on application development | PaaS              |
| Ready-to-use software            | SaaS              |

# Interview Questions

### 1. What are the three cloud service models?

* Infrastructure as a Service (IaaS)
* Platform as a Service (PaaS)
* Software as a Service (SaaS)

---

### 2. What is IaaS?

IaaS provides virtualized infrastructure such as servers, storage, and networking while allowing customers to manage the operating system and applications.

---

### 3. What is PaaS?

PaaS provides a platform for developing and deploying applications without managing the underlying infrastructure.

---

### 4. What is SaaS?

SaaS delivers complete software applications over the Internet that users can access through a browser or app.

---

### 5. Give examples of each service model.

* **IaaS:** Amazon EC2, Amazon EBS, Amazon VPC
* **PaaS:** AWS Elastic Beanstalk, AWS App Runner, Amazon RDS
* **SaaS:** Gmail, Microsoft 365, Google Workspace, Zoom

---

# Key Takeaways

* Cloud Service Models define how cloud services are delivered to customers.
* **IaaS** provides infrastructure with maximum control.
* **PaaS** provides a development platform, allowing developers to focus on code.
* **SaaS** delivers fully managed software applications to end users.
* Choosing the right service model depends on the level of control, management, and flexibility required.
