# 07 - Cloud Storage

# 💾 Cloud Storage

## 📖 Introduction

**Cloud Storage** is a cloud computing service that allows users and organizations to store, manage, retrieve, and back up data over the Internet instead of storing it on local hard drives or physical storage devices.

Cloud storage is one of the most important services in cloud computing because it provides **high availability, scalability, durability, security, and cost efficiency**.

Cloud providers such as **Amazon Web Services (AWS)**, **Microsoft Azure**, and **Google Cloud Platform (GCP)** offer different types of storage services to meet various business needs.

---

# What is Cloud Storage?

**Cloud Storage** is a service that stores data on remote servers managed by a cloud provider. Users can access their data from anywhere using an Internet connection.

### Definition

> **Cloud Storage is a service that stores digital data on remote cloud servers, allowing users to access, manage, and retrieve data securely over the Internet.**

---

# Why Do We Need Cloud Storage?

Traditional storage systems have several limitations:

* Limited storage capacity
* High hardware costs
* Risk of hardware failure
* Difficult backup management
* Limited accessibility
* High maintenance costs

Cloud Storage solves these problems by providing secure, scalable, and reliable storage services.

# Types of Cloud Storage

There are three primary types of cloud storage:

1. Object Storage
2. Block Storage
3. File Storage

---

# 1. Object Storage

## Definition

Object Storage stores data as **objects** instead of files or blocks.

Each object contains:

* Data
* Metadata
* Unique Identifier

It is ideal for storing large amounts of unstructured data.

---

## Characteristics

* Highly scalable
* Internet accessible
* Stores unstructured data
* Cost-effective
* Supports billions of objects

---

## Use Cases

* Images
* Videos
* Documents
* Website Assets
* Data Backup
* Log Files

---

## AWS Example

**Amazon S3 (Simple Storage Service)**

---

# 2. Block Storage

## Definition

Block Storage divides data into small blocks.

Each block has its own unique address and behaves like a traditional hard disk.

---

## Characteristics

* High performance
* Low latency
* Fast read/write operations
* Suitable for databases

---

## Use Cases

* Virtual Machines
* Databases
* Enterprise Applications
* Operating Systems

---

## AWS Example

**Amazon Elastic Block Store (EBS)**

---

# 3. File Storage

## Definition

File Storage organizes data using a traditional folder and file hierarchy.

It supports shared access by multiple users.

---

## Characteristics

* Shared file system
* Easy file management
* Standard file protocols
* Suitable for collaboration

---

## Use Cases

* Shared Documents
* Home Directories
* Content Management Systems
* Team Collaboration

---

## AWS Example

**Amazon Elastic File System (EFS)**

---

# Best Practices

* Encrypt sensitive data.
* Enable Multi-Factor Authentication (MFA).
* Regularly back up important files.
* Apply least-privilege access policies.
* Monitor storage usage.
* Choose the appropriate storage class.
* Enable versioning for critical files.
* Review lifecycle policies to optimize costs.

### 4. What is the difference between Block Storage and File Storage?
