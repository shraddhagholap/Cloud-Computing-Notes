# 01 - Introduction to Cloud Computing

# ☁️ Introduction to Cloud Computing

## 📖 What is Cloud Computing?

**Cloud Computing** is the delivery of computing services such as **servers, storage, databases, networking, software, analytics, and artificial intelligence (AI)** over the Internet ("the cloud") instead of using local computers or on-premises servers.

Instead of purchasing and maintaining physical hardware, users can access computing resources on demand and pay only for what they use.

---

# 📚 Definition

> **Cloud Computing** is the on-demand delivery of IT resources over the Internet with pay-as-you-go pricing.

This means users can quickly provision computing resources whenever needed without owning or managing physical infrastructure.

---

# 🌍 Real-World Example

Imagine you want to store your photos.

### Traditional Method

* Store photos on your laptop or hard drive.
* If the device is lost or damaged, the photos may also be lost.
* Storage is limited by your device's capacity.

### Cloud Computing

* Upload photos to a cloud storage service.
* Access them from any device with an Internet connection.
* Easily increase storage without buying new hardware.

Examples include cloud storage platforms, online email services, video streaming platforms, and online collaboration tools.

---

# 🏢 Traditional IT vs Cloud Computing

| Traditional IT          | Cloud Computing                |
| ----------------------- | ------------------------------ |
| Buy physical servers    | Rent virtual resources         |
| High upfront investment | Pay only for usage             |
| Manual maintenance      | Managed by cloud provider      |
| Limited scalability     | Easily scalable                |
| Longer deployment time  | Resources available in minutes |

---

# ☁️ How Cloud Computing Works

Cloud providers own and manage large data centers around the world.

When a user requests a service:

1. The request is sent over the Internet.
2. The cloud provider allocates the required resources.
3. The application or data is delivered to the user.
4. Resources can be scaled up or down based on demand.

# 🏗 Components of Cloud Computing

## 1. Compute

Provides virtual machines, containers, and serverless computing to run applications.

**Examples**

* Virtual Machines (VMs)
* Containers
* Serverless Functions

---

## 2. Storage

Stores files, images, videos, backups, and application data securely.

**Examples**

* Object Storage
* Block Storage
* File Storage

---

## 3. Networking

Connects cloud resources securely and enables communication between systems.

**Examples**

* Virtual Networks
* Load Balancers
* DNS Services

---

## 4. Databases

Cloud providers offer managed databases that reduce administrative overhead.

**Examples**

* Relational Databases
* NoSQL Databases

# 🎤 Interview Questions

### 1. What is Cloud Computing?

Cloud Computing is the on-demand delivery of computing services such as servers, storage, databases, networking, and software over the Internet with pay-as-you-go pricing.

---

### 2. Why is it called "Cloud" Computing?

The term **"cloud"** represents the Internet, where computing resources are hosted in remote data centers instead of on local machines.

---

### 3. What are the main components of Cloud Computing?

* Compute
* Storage
* Networking
* Databases
* Applications

---

### 4. Name three major cloud providers.

* Amazon Web Services (AWS)
* Microsoft Azure
* Google Cloud Platform (GCP)

---

### 5. What is the biggest advantage of Cloud Computing?

One of the biggest advantages is **on-demand scalability**, allowing organizations to increase or decrease resources as needed without purchasing physical hardware.
