# 06 - Virtualization

# 💻 Virtualization

## 📖 Introduction

**Virtualization** is one of the core technologies behind **Cloud Computing**. It allows multiple **Virtual Machines (VMs)** to run on a single physical computer by sharing hardware resources efficiently.

Instead of using one physical server for one operating system, virtualization enables a single physical server to host multiple operating systems simultaneously.

Cloud providers such as **AWS, Microsoft Azure, and Google Cloud Platform (GCP)** use virtualization to provide scalable, cost-effective, and highly available cloud services.

---

# What is Virtualization?

**Virtualization** is the process of creating a virtual version of computing resources such as servers, storage, operating systems, networks, or desktops.

It enables multiple virtual environments to run independently on a single physical machine.

### Definition

> **Virtualization is the technology that creates virtual instances of hardware or software, allowing multiple operating systems and applications to share the same physical resources efficiently.**

---

# Why Do We Need Virtualization?

Before virtualization, organizations followed the **One Server = One Operating System** model.

This caused:

* Poor hardware utilization
* High infrastructure cost
* Increased power consumption
* More maintenance
* Wasted resources

Virtualization solves these problems by allowing multiple virtual machines to share a single physical server.

---

# Components of Virtualization

## 1. Physical Server

The actual hardware containing:

* CPU
* Memory (RAM)
* Storage
* Network Interface Cards (NICs)

---

## 2. Hypervisor

A **Hypervisor** is software that creates and manages Virtual Machines.

It allocates CPU, memory, storage, and networking resources to each VM.

Examples:

* VMware ESXi
* Microsoft Hyper-V
* KVM
* Xen

---

## 3. Virtual Machine (VM)

A Virtual Machine is a software-based computer.

Each VM has its own:

* Operating System
* CPU allocation
* RAM allocation
* Storage
* Applications

Each VM operates independently.

---

# Types of Hypervisors

There are two main types of hypervisors.

---

# Type 1 Hypervisor (Bare Metal)

## Definition

A Type 1 Hypervisor runs directly on physical hardware without requiring a host operating system.

### Architecture

```text
Applications
      │
Guest Operating Systems
      │
Type 1 Hypervisor
      │
Physical Hardware
```

### Advantages

* Better performance
* High security
* Lower overhead
* Ideal for cloud environments

### Examples

* VMware ESXi
* Microsoft Hyper-V
* Xen
* KVM

---

# Type 2 Hypervisor (Hosted)

## Definition

A Type 2 Hypervisor runs on top of an existing operating system.

### Architecture

```text
Applications
      │
Guest Operating Systems
      │
Type 2 Hypervisor
      │
Host Operating System
      │
Physical Hardware
```

### Advantages

* Easy installation
* Suitable for learning
* Great for testing

### Disadvantages

* Lower performance
* Higher overhead

### Examples

* Oracle VirtualBox
* VMware Workstation
* VMware Fusion

---

# Type 1 vs Type 2 Hypervisor

| Feature      | Type 1               | Type 2                         |
| ------------ | -------------------- | ------------------------------ |
| Installation | Directly on Hardware | On Host Operating System       |
| Performance  | High                 | Medium                         |
| Security     | High                 | Medium                         |
| Overhead     | Low                  | High                           |
| Best For     | Data Centers         | Personal Computers             |
| Examples     | VMware ESXi, Hyper-V | VirtualBox, VMware Workstation |

# Types of Virtualization

## 1. Server Virtualization

Creates multiple virtual servers from one physical server.

Example:

AWS EC2 Instances

---

## 2. Storage Virtualization

Combines multiple storage devices into one virtual storage pool.

Benefits:

* Better storage management
* Easier backup
* Higher availability

---

## 3. Network Virtualization

Creates virtual networks independent of physical hardware.

Examples:

* AWS VPC
* Azure Virtual Network

---

## 4. Desktop Virtualization

Allows users to access desktops remotely.

Example:

Virtual Desktop Infrastructure (VDI)

---

## 5. Application Virtualization

Applications run independently without full installation on the user's operating system.

Example:

Microsoft App-V

---

# Advantages of Virtualization

* Better hardware utilization
* Reduced infrastructure cost
* Lower power consumption
* Easier backup and recovery
* High availability
* Faster provisioning
* Simplified management
* Improved scalability
* Disaster recovery support

---

# Disadvantages of Virtualization

* Initial setup complexity
* Requires skilled administrators
* Hardware failure can affect multiple VMs
* Licensing costs for some hypervisors
* Performance overhead in hosted virtualization

---

# Virtualization in Cloud Computing

Virtualization is the foundation of cloud computing.

Cloud providers use virtualization to:

* Create Virtual Machines
* Allocate resources dynamically
* Isolate customers
* Improve scalability
* Reduce costs
* Maximize hardware utilization

Without virtualization, cloud computing would not be practical.

---

            │
            ▼

            ▼

            │
            ▼

            │

---

# Real-World Example

A software company has one powerful physical server with:

* 64 CPU Cores
* 256 GB RAM
* 10 TB Storage

Using virtualization, the company creates:

* VM 1 → Web Server
* VM 2 → Database Server
* VM 3 → Application Server
* VM 4 → Development Server
* VM 5 → Testing Server

Instead of purchasing five separate physical servers, all workloads run efficiently on one machine.

# Interview Questions

### 1. What is Virtualization?

Virtualization is the process of creating virtual versions of computing resources such as servers, operating systems, storage, and networks.

---

### 2. What is a Hypervisor?

A Hypervisor is software that creates and manages Virtual Machines by allocating hardware resources.

---

### 3. What are the two types of Hypervisors?

* Type 1 (Bare Metal)
* Type 2 (Hosted)

---

### 4. Which Hypervisor is used in Cloud Computing?

Cloud providers mainly use **Type 1 (Bare Metal) Hypervisors** because they offer better performance, security, and scalability.

---

### 5. What is the difference between Virtualization and Cloud Computing?

Virtualization creates virtual resources on physical hardware, while Cloud Computing delivers those resources as on-demand services over the Internet.
